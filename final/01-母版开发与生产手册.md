## 0. 一句话架构

**风格三件套定死视觉（style.css + templates.html + design-system.md），AI 依 catalog 选母版、写 plan.json，render 实例化出图（HTML+PNG），母版覆盖不了时 AI 在风格词汇内受控即兴，用顺了转正入库，微调交给编辑器。**

```
文章 → AI 提炼 → 用户定风格（style-picker.md）→ AI 读 catalog 选母版 → 写 plan.json
     → node render.mjs runs/<任务>/ → out/P01-xxx.html + P01.png + … + preview.png
     → 人审 → 交付 →（可选）编辑器微调
```

AI 的职责 = **选**（风格/母版/槽位图）+ **填**（plan.json 按槽位申报内容）+ **受控即兴**（仅当母版覆盖不了）。填充、截图、校验、打包全是脚本动作。

## 2. 生产 SOP（v2 · 七步）

1. **任务初始化**：建 `runs/<日期-主题>/`，收集素材（文案+图片清单）。
2. **内容提炼**：AI 整理/提炼/升格，定页数与每页语义。**纪律：可润色不可编造**——数字与承诺必须有素材出处。
3. **风格选择**：AI 依 `style-picker.md` 推荐 1-2 种，用户拍板或直接点名。
4. **素材图片识别**：按 §3.6 图片决策表逐张分类定处理方式（AI 判断，裁切由 CSS 机械执行）。
5. **逐页选母版**：AI 读 `catalog.md` 对应风格段落（语义组+四栏）选定每页版式；精确条数/字数在实例化时读母版 repeat 注释获取。
6. **写 plan.json**：按选中母版的槽位（data-slot/占位符名）申报内容——文字/图片路径/条目数组/受控富文本片段。**母版覆盖不了时走受控即兴**（§4.2）：layout 登记 `custom/<语义名>`，AI 直接产整页 markup。
7. **跑 render → 三层校验 → 交付**：`node render.mjs runs/<任务>/`；交付目录只含 `P*.html` + `*.png` + `assets/`（+ preview.png + 可选 fields.json）；plan.json 留 runs/ 不进交付。

## 3. 母版开发规范（写/改母版必读）

### 3.1 结构

- 每母版 = templates.html 里一个 `<section data-layout="<风格内唯一id>">`，section 前有**人读说明头**（标题/适合/字数——与 catalog 条目同源同步）。
- 内部有且只有一个画布根：`<div class="p-page" data-artwork data-size="1080x1440">`（或风格自定根类，manifest 的 root 声明它）。
- templates.html 顶部含**画廊三合一头部**：语义组导航锚点 + 风格看板（色板/字体/字号层级/画布规格）——与 style.css 同源，改 CSS 三处一起改（css/templates/看板；render 校验此同步）。
- 一母版一页；交付产物是 render 拆出的独立 `P01-xxx.html`（`P\d+` 命名），templates.html 永远是源仓库，不进交付区。

### 3.2 CSS 纪律（唯一文件 style.css，内部双段制）

```css
/* ===== 共享段：全风格母版公用的组件类/基础类 ===== */
/* ===== 专属段：仅个别母版使用的类，集中放尾部，类名强制母版前缀（如 .n01-shock）===== */
```

- 扁平选择器（编辑器未验证嵌套）；px 或 cqw（cqw 需根节点 `container-type:size`）。
- **禁** vh/vw、`position:fixed`、窗口断点 `@media`、动画/过渡。
- 画布 1080×1440 写在根节点；**section 内禁止 `<style>`**——一切样式进 style.css。
- 母版间布局差异用类名/修饰类表达；多容器同页 cqw 互不干扰（各 section 根自带 container-type）。

### 3.3 图层标记契约（照抄 pageApp v1.9 §4.1，逐字执行）

| 属性 | 值 | 放在哪 |
|---|---|---|
| `data-layer` | 全页唯一 kebab-case 英文 id | 要成为图层的元素 |
| `data-label` | 中文短名 | 同上 |
| `data-type` | `text`/`group`/`image` | 同上（可省） |
| `data-editable` | `"text"` | 包住文字的叶子元素 |
| `data-group` | 无值 | 组合容器 |
| `data-slot` | `"image"` | 仅 `<img>` |

硬规则：容器标 group、文字标叶子；`data-layer` 全页唯一禁中文/空格/首尾空白；`data-slot="image"` 只落 `<img>`；根节点不加 data-layer；正文不进伪元素 content；高亮 span 与 `<br>` 安全。

### 3.4 槽位与 repeat（唯一配置点=母版注释）

- 文字槽：`<h1 data-slot="标题" data-layer="cover-title" data-editable="text">{{标题}}</h1>`——**占位符名 = data-slot 名 = plan.json 的 fields 键**。
- 图片槽：`<img data-slot="image" data-layer="cover-image" data-ratio="4:3" src="{{图1}}">`。
- **repeat 语法规范（全库唯一语法定义处=本节；数值只写在母版注释里）**：

```html
<!-- repeat ×<min>-<max>: <克隆规则一句>；<条数-字数联动一句> -->
<div class="item" data-slot="items">…完整单元…</div>
```

  - 任何重复型组件（清单/待办/卡片/行/通知/图卡…）都适用；一个母版可有多处 repeat 槽，各管各的。
  - 区间与联动字数**只配置在这里**；catalog 条目只写语义（"弹性条目清单"），不写数字。
  - 布局自适应用 flex/grid 弹性实现（条数变化自动伸缩），母版设计期保证 3-8 条全区间不溢出。
  - render 解析注释克隆单元；plan.json 传数组；AI 不手工复制节点。

### 3.5 就地限制（必写）

每个 section 的说明头写死该母版全部填字纪律（标题字数/副题/槽位比例/hl 数量与位置）。限制注释是**机器可读的**——render 解析"≤N字"做字数软校验。写实测值：该字号下不折行不溢出。

### 3.6 图片决策表（素材四分类，AI 识别后对号入座）

| 素材类型 | 识别特征 | 处理 | 去向 |
|---|---|---|---|
| **手机截图** | 竖长（≈9:19.5）、状态栏/圆角特征 | 套手机壳槽。**手机框由 render 自动兜底**：`frame-img` 类装饰槽若 plan.json 未指定，自动解码 `styles/assets/iphone-frame.b64` 内嵌 | 手机壳母版（tech-blue N04/N11 等） |
| **窗口截图** | 顶栏/地址栏/标题栏特征，横版 | 图进窗口内容区槽位；原图自带边框的用无边框槽避免双框 | 各风格窗口类母版 |
| **干净内容图** | 主体明确、构图完整 | 直接用，槽位比例 cover 裁切 | 任意图槽 |
| **杂乱图** | 全屏截图/聊天长图/多区域 | AI 读图选区 → plan.json 写 `crop` 描述（如 `"下 55%"`/object-position），render 用 CSS 区域显示实现 | 裁剪后进任意图槽 |

总则：PNG/JPEG/WebP；裁切由 CSS 机械完成，AI 不做像素级编辑，人审 PNG 是裁切质量最终把关；像素级精确裁剪（真改文件）=可选增强，v1 不做；形状严重不符换槽位/换母版，不硬塞。

### 3.7 字体策略

编辑器导出 PNG 只认 base64 内嵌与本机已装字体；CDN/外链字体屏显正常、编辑器导 PNG 必然回退（pageApp §3.3）。中文字体用本机字体栈；小体积西文字体 render 出页时 base64 内嵌。生图自己的 CDP 截图不受此限。

### 3.8 禁区

产物无 `<script>`（图标 render 时内联 SVG）；无动画/轮播/滚动；无外部 `<link>`、无 `<img src>` 外链（pageApp 构建期拒绝）。

## 4. 选型、画廊与受控即兴

### 4.1 选型链

1. 人/AI 读 `style-picker.md` 定风格；
2. AI 读 `catalog.md` 对应风格段落，按语义组+四栏选母版；
3. 精确条数/字数从选中母版的 repeat 注释与说明头读取。
- catalog 与母版说明头**同源同步**（改一处另一处跟改；render 校验同步）。

### 4.2 受控即兴与转正

- 即兴边界：只用 style.css 既有类 + 遵循 design-system.md；layout 登记 `custom/<语义名>`；**禁止内联样式、自造 CSS 变量、新类名**（新类=风格演进=用户过目改 style.css 并登记 design-system）。
- 即兴页校验自动升级：形态校验必查 + `--check-geometry` 默认开。
- 转正：同名 `custom/<名>` 累计 ≥2 次 → AI 提示建议入库 → 按 §3 规范重整（补标记/占位符/限制注释/入 templates.html+catalog）→ 用户目检 → 真实任务回归一次。转正不是复制粘贴当次产物。
- 即兴两次不满意同一内容 → 直接走转正管道，不无限即兴。

### 4.3 画廊（templates.html 三合一）

templates.html 既是仓库也是画廊：顶部导航（语义组锚点）+ 风格看板（色板/字体/字号/画布规格，与 style.css 同源）+ 分组区头 + 母版纵向平预览（带说明头）。浏览器打开即所见。iframe 方案弃用（它以每母版独立文件为前提，与单文件存储矛盾）。人审细节开画廊，总览看 preview.png。

## 5. render 实例化器规格

| 项 | 内容 |
|---|---|
| 输入 | `runs/<任务>/plan.json` + 素材图片 |
| 步骤 | 按 layout 从 templates.html 抽 section（custom 页直用 AI markup）→ 填槽/克隆 repeat/执行 crop → **frame-img 自动兜底手机框**（解码 b64）→ 图标 SVG 内联 → style.css 内联 → 图片内嵌或落 assets → 包独立壳写 `P<nn>-<名>.html` → Chrome 逐页截图 1080×1440 → 生成 preview.png 总览 → 生成 `editor.manifest.json` + `fields.json` |
| 硬校验（即停） | `{{` 残留 / 图片缺失或格式不符 / 根节点与画布确认 / `data-layer` 全页唯一 / 必填槽为空 / plan 字段与槽位对不上 |
| 软校验（WARN） | 字数超限（解析限制注释比对）/ 图片与槽位比例差异大（提示裁切量）/ catalog 与母版说明头不同步 |
| 即兴页专项 | 形态校验（单 style 块/无禁区属性/引用风格 CSS）+ `--check-geometry`（溢出/遮挡/裁切，裁自旧 validate.mjs，custom 页默认开） |
| 地基 | render/lib/（cdp、find-chrome）；内联与资产段裁自旧 build.mjs；manifest 生成参考旧 pipeline |

**plan.json（过程件，AI 写）与 fields.json（交付件，render 转写生成）是同一数据的两种身份**：前者驱动实例化，后者满足编辑器契约初稿（pageApp §6）。
