## 0. 一句话架构

**风格目录定死视觉**（构成清单权威定义在 `styles/style-picker.md`，全在 `styles/<风格>/` 内），AI 依 style-picker 定风格、读该风格 catalog 选母版、写 plan.json，render 实例化出图（HTML+PNG），母版覆盖不了时 AI 在风格词汇内受控即兴，用顺了转正入库，微调交给编辑器。**

```
文章 → AI 提炼 → 用户定风格（style-picker.md + 画廊 templates.html）→ AI 读该风格 catalog.md 选母版 → 写 plan.json
     → node script/render.mjs <任务运行区>/ --delivery=<交付目录>
     → 产物先全写任务运行区 → 三层校验与逐页截图全过 → 白名单拷贝交付目录（§6）
     → 人审 →（可选）编辑器微调
```

AI 的职责 = **选**（风格/母版/槽位图）+ **填**（plan.json 按槽位申报内容）+ **受控即兴**（仅当母版覆盖不了）。填充、截图、校验、交付全是脚本动作。**技能安装目录运行期只读**，临时脚本与过程件一律在任务运行区执行（§6）。

## 2. 生产 SOP（v2.1 · 八步）

> 全流程图（SVG·浏览器打开）：[02-SOP全流程图.html](02-SOP全流程图.html) —— 八步主线、判定分支、返修循环、受控即兴分级支线、转正管道、只读资产层的唯一权威视图，与本节同步维护。

1. **任务初始化**：在 agent 临时工作区建 `runs/<日期-主题>/` 作任务运行区（§6），收集素材（文案+图片清单）。
2. **内容提炼**：AI 整理/提炼/升格，定页数与每页语义。**纪律：可润色不可编造**——数字与承诺必须有素材出处。
3. **风格选择**：AI 依 `style-picker.md` 的名片推荐 1-2 种，用户拍板或直接点名；需要看版式时打开该风格 `templates.html` 画廊。
4. **素材盘点与识别**：按 §3.6 四分类逐张盘点（手机截图/窗口截图/干净图/杂乱图）——**只做资产属性分类，产出素材清单**（供⑤选母版与⑥匹配使用）；处理决策在⑥（此时已确定槽位与比例）。
5. **逐页选母版**：读 `styles/<风格>/catalog.md`（语义组+四栏）选定每页版式；**输入含素材类型分布（④）**——有手机截图的页才考虑手机壳母版；精确条数与字数从选中母版的 repeat 注释与说明头读取。
6. **图片×槽位匹配**：决策表落地——手机截图→手机壳槽（框自动内嵌）/ 窗口截图→窗口槽（防双框）/ 干净图→直接用 / 杂乱图→AI 读图选区 crop；裁切由 CSS 机械执行，AI 不做像素级编辑；不符→换槽/换母版。
7. **写 plan.json**：按槽位申报内容（fields 键=槽位锚：文字槽={{槽名}}=data-layer id、图槽=图槽 data-layer id；数组=repeat 条目；受控富文本 span.hl/br/strong）。**母版覆盖不了时走受控即兴**（§4.2 分级阶梯）：layout 登记 `custom/<语义名>`。
8. **render → 三层校验 → 交付**：`node script/render.mjs <任务运行区>/ --delivery=<YYYY-MM-DD-小标题>`；产物先全写运行区，校验与截图全过后才按白名单（`P*.html` + `P*.png` + `preview.png`）拷进交付目录；plan.json 与过程件留运行区，不进交付（§6）。

### 2.1 plan.json 规范（实例化输入的唯一格式）

**身份**：plan.json 是 AI 的唯一产出物，过程件（留任务运行区，不进交付）；render 把它转写为编辑器契约的 `fields.json`（同样先写运行区）——同一份数据，前者驱动填充、后者供编辑器读取。转写时 `fields.json` 的键统一为页面真实 `data-layer` id：repeat 条目短名映射回单元元素的 data-layer，并按克隆序号加 `-2/-3` 后缀（pageApp「fields.json」一节）。

```json
{ "style": "tech-blue",
  "delivery": "2026-11-15-ai工具盘点",
  "pages": [
    { "nn": "01", "layout": "N02-dialog-cover",
      "fields": {
        "title": "真正能让你<span class=\"hl\">少加班</span>的 AI 工具",
        "n02-img-1": "shots/a.png",
        "items": [ { "num": "01", "t": "Cursor · AI 编辑器", "d": "写代码快 5 倍" } ] } },
    { "nn": "02", "layout": "custom/双栏金句",
      "markup": "<div class=\"artwork-page\" data-artwork data-size=\"1080x1440\">…AI 受控即兴整页…</div>" } ] }
```

规则：
1. `fields` 键 = 母版槽位锚，分两层：**顶层文字槽 = {{槽名}} = data-layer id；图槽 = 图槽的 data-layer id**（三处同名）；**repeat 单元内用条目短名**（`n/t/d`…），clone 时 data-layer 自动加序号后缀。render 校验槽位一一对应——缺槽、未知槽、类型不符即停；
2. 字符串值可含受控富文本（仅 `span.hl` / `br` / `strong`）；数组对应 repeat 槽，render 按母版注释克隆并校验区间（超出 ×min-×max 即停）；
3. 图片值 = 相对路径；render **同时**把图内嵌为 dataURL（交付页自包含）并把原件复制进运行区 `assets/` 作副本；杂乱图加 `"crop": "下 55%"` 或 `"left 30%"`（parseCrop 只收「方位 + 百分比」，不收 `object-position:` 字面值）；
4. 即兴页：`layout: "custom/<语义名>"`，`markup` 附整页根节点 HTML（**根类固定 `.artwork-page`**），须过形态校验 + 几何体检；
5. 填表前必须先读选中母版——不预判槽位、不虚构字段名；
6. `delivery`（可选）：交付目录路径，等价于命令行 `--delivery`；相对路径按当前工作目录解析，目录命名 `YYYY-MM-DD-<小标题>`（§6）。

## 3. 母版开发规范（写/改母版必读）

> **完整创建规范**：[03-母版创建规范.md](03-母版创建规范.md) —— 母版解剖（五必备 + 两按需）、HTML/CSS/data-* 全部细则、repeat 语法、说明头必填字段、创建工作流七步（**写新母版的流程，与本节生产 SOP 八步不同**）、二次开发三层边界、最小合规示例、验收清单。写或改母版时以它为准，本节为生产摘要层。

### 3.1 结构

- 每母版 = templates.html 里一个 `<section data-layout="<风格内唯一id>">`，section 前有**人读说明头**（标题/适合/字数——与 catalog 条目同源同步）。
- 内部有且只有一个画布根：`<div class="artwork-page" data-artwork data-size="1080x1440">`——**根类名当前实现固定 `.artwork-page`**（render 的 `rootOf()` / `editor.manifest.json` 的 root / Chrome 截图 selector 都认它），不得自造。
- templates.html 顶部含**画廊三合一头部**：语义组导航锚点 + 风格看板（色板/字体/字号层级/画布规格）——与 style.css 同源，改 CSS 三处一起改（css/templates/看板；同步靠入库纪律，v1 无自动校验）。
- 一母版一页；交付产物是 render 拆出的独立 `P01-xxx.html`（`P\d+` 命名），templates.html 永远是源仓库，不进交付区。

### 3.2 CSS 纪律（唯一文件 style.css，内部双段制）

```css
/* ===== 共享段：全风格母版公用的组件类/基础类 ===== */
/* ===== 专属段：仅个别母版使用的类，集中放尾部，类名强制母版前缀（如 .n01-shock）===== */
```

- 扁平选择器（编辑器未验证嵌套）；px 或 cqw（cqw 需根节点 `container-type:size`）。
- **禁** vh/vw、`position:fixed`、窗口断点 `@media`、动画/过渡。
- 画布 1080×1440 写在根节点；**section 内禁止 `<style>`**——一切样式进 style.css。
- 母版间布局差异用类名/修饰类表达；多容器同页 cqw 互不干扰（各 section 根自带 container-type）。
- **画廊 chrome 豁免**：templates.html 的导航/看板/锚点脚本（section 之外的仓库层设施）允许自带 `<style>`/`<script>`——它们只服务画廊浏览，render 拆页只取 section 内容，不会进入交付 P 页。

### 3.3 图层标记契约（照抄 pageApp v1.9「L2 推荐标记契约 · 属性表」，逐字执行）

| 属性 | 值 | 放在哪 |
|---|---|---|
| `data-layer` | 全页唯一 kebab-case 英文 id | 要成为图层的元素 |
| `data-label` | 中文短名 | 同上 |
| `data-type` | `text`/`group`/`image` | 同上（可省） |
| `data-editable` | `"text"` | 包住文字的叶子元素 |
| `data-group` | 无值 | 组合容器 |
| `data-slot` | `"image"` | 仅 `<img>` |

硬规则：容器标 group、文字标叶子；`data-layer` 全页唯一禁中文/空格/首尾空白；`data-slot="image"` 只落 `<img>`；根节点不加 data-layer；正文不进伪元素 content；高亮 span 与 `<br>` 安全。

### 3.4 槽位与 repeat（数值唯一配置点=母版注释）

- 文字槽：`<h1 data-layer="cover-title" data-label="标题" data-editable="text">{{标题}}</h1>`——**占位符名 = data-layer id = plan.json 顶层 fields 键**。**`data-slot` 只用于 `<img>`**（编辑器换图槽，见 §3.3），文字元素禁用。
- 图片槽：容器（如 `<div class="ph-img" data-fit="cover">`，`data-fit` 为 cover/contain，默认 cover）内含**唯一实图层** `<img class="ph-img__img" data-slot="image" data-layer="cover-image" data-ratio="4:3" src="1×1 透明 GIF">`——空 src 时容器显示占位标签、布局与有图一致；render 与编辑器**都只替换这个 img 的 src**（dataURL），crop 时外包一层裁切容器；容器补 `data-filled` 隐藏占位标签。`data-slot/data-layer/data-label/data-ratio` 原样保留，否则编辑器扫不出换图层。容器上不写 `data-img`，CSS 里不写 `--img` 变量——图片只有「替换 `<img>` 的 src」这一条通道。
- **repeat 槽语法（全库唯一语法定义处=本节；数值只写在母版注释里）**：

```html
<!-- repeat ×<min>-<max>: <克隆规则一句>；<条数-字数联动一句> -->
<div class="item" data-repeat="items">…完整单元（占位符用短名 {{num}}/{{t}}/{{d}}）…</div>
```

  - 单元元素必须带 `data-repeat="<数组键名>"`（plan.json 中数组字段的键，机器锚点）；注释承载区间与条数-字数联动（机器解析的另一半）——两者合起来才是完整的 repeat 声明。
  - plan.json 传对象数组（键 = 单元内短占位符名）→ render **从后往前**克隆（防位移）、校验区间、对克隆体 data-layer 加 `-2/-3` 序号后缀保持每页唯一。
  - 布局自适应用 flex/grid 弹性实现（条数变化自动伸缩），区间两端都不溢出、不空塌。
  - AI 不手工复制节点；填充顺序由 render 固定：repeat（后往前）→ 图片槽 → 顶层文字槽 → 残留校验。

### 3.5 就地限制（必写）

每个 section 的说明头写死该母版全部填字纪律（标题字数/副题/槽位比例/hl 数量与位置）。限制注释是**机器可读的**——render 解析 `≤N字`（或 `≤N字符`，同义）做字数软校验。写实测值：该字号下不折行不溢出。

**计数口径（唯一，别自创）——1 字 = 1 个字符位**：

| 内容 | 记几个字 | 例 |
|---|---|---|
| 汉字 | 1 / 字 | 「横评」= 2 |
| 英文字母、数字 | 1 / 字符（**不按单词**） | `VSCode` = 6，`$20/月` = 5 |
| 全角与半角标点 | 1 / 个 | 「，」「。」「:」「/」各 1 |
| 空格、换行 | 0（不计） | — |
| HTML 标签（`<span class="hl">`） | 0（去掉后数） | — |
| emoji | 1 / 个 | 👍 = 1 |

理由：母版宽度按字符位算，`WWWW` 与 `iiii` 都不超过一个汉字宽，按码点才是保守估计；按"单词"会严重低估（`VSCode` 记 1 会直接溢出）。`字` 与 `字符` 只是历史写法差异（中文槽写字、ASCII 槽写字符），**校验口径相同，两者都会被解析**。

- **容差**：超限 20% 以内不告警（同一字号下偶发换行可接受），WARN 会同时打印「限值」和「容差上限」，方便判断是改文案还是调限值。
- **限值是实测值，不是估的**：新建/改母版时用最长真实文案试渲染，量出该容器实际能放多少字位，限值取「实测 − 余量」而非拍脑袋。例：N21 结论条实测 28 字宽松、34 字几乎贴边，限值定 26。
- **每行限制**（`(2行,每行≤7字)`）目前**只人审，不机器校验**——超限只能靠目检 PNG 或 `--check-geometry`（仅 custom 页）发现。

### 3.6 图片决策表（④ 盘点识别 + ⑥ 匹配落地的依据）

| 素材类型 | 识别特征 | 处理 | 去向 |
|---|---|---|---|
| **手机截图** | 竖长（≈9:19.5）、状态栏/圆角特征 | 套手机壳槽。**手机框由 render 单源内嵌**：`frame-img` 类装饰槽自动读取 `styles/assets/iphone-frame.png` 现场编码内嵌（缺文件即停） | 手机壳母版（tech-blue N04 等） |
| **窗口截图** | 顶栏/地址栏/标题栏特征，横版 | 图进窗口内容区槽位；原图自带边框的用无边框槽避免双框 | 各风格窗口类母版 |
| **干净内容图** | 主体明确、构图完整 | 直接用，槽位比例 cover 裁切 | 任意图槽 |
| **杂乱图** | 全屏截图/聊天长图/多区域 | AI 读图选区 → plan.json 写 `crop` 描述（`"下 55%"` / `"left 30%"` / `"bottom 40%"`），render 外包裁切容器 + CSS 定位实现 | 裁剪后进任意图槽 |

总则：PNG/JPEG/WebP；裁切由 CSS 机械完成，AI 不做像素级编辑，人审 PNG 是裁切质量最终把关；像素级精确裁剪（真改文件）=可选增强，v1 不做；形状严重不符换槽位/换母版，不硬塞。

### 3.7 字体策略

默认字体策略 = **本机字体栈**：源模板不引 CDN、不加载 webfont、不做 base64 内嵌；`--serif/--sans/--mono` 直接声明本机字体族（命中即用，未装按栈回退）。理由是编辑器导出 PNG 只认本机已装字体与 base64 内嵌（pageApp「资源」一节），走本机栈可保证画廊、交付页、编辑器导出三处字形一致，且离线可用；生图自己的 CDP 截图不受外链限制。`script/render.mjs` 出页时仍剥离 `@import` 行作为防御性校验（正常情况下源 CSS 已无 @import）。`styles/assets/fonts/` 的 fontsource 分片当前未接入，保留作后续 webfont 可选增强的原料。

### 3.8 禁区

产物无 `<script>`；无动画/轮播/滚动；无外部 `<link>`、无 `<img src>` 外链（编辑器打包器拒绝）。图标 SVG 内联当前未实现（tech-blue 无字形图标，需要时按 TODO 附表立项）。

## 4. 选型、画廊与受控即兴

### 4.1 选型链

1. 人/AI 读 `style-picker.md` 定风格；
2. AI 读 `styles/<风格>/catalog.md`，按语义组+四栏选母版——**输入含素材类型分布（④）**：有手机截图的页才考虑手机壳母版；
3. 精确条数/字数从选中母版的 repeat 注释与说明头读取（⑦ 填表前）。
- **两层职能，不重复配置**：catalog 的"字数语义" = 从母版 repeat 注释蒸馏出的**选型语义**（判断内容体量合不合脚）；精确数字只在母版注释（唯一配置点）——**catalog 管选型判断，repeat 管填充校验**。
- catalog 与母版说明头**同源同步**（改一处另一处跟改；靠入库纪律，v1 无自动校验）。
- **catalog 条目格式**（四栏示例）：

  #### N10 工具清单
  适合：3-8 条量级的工具/资源推荐，左文右图双栏
  不适合：每条需要长说明（d 只有一行）；纯图片展示
  可以变：右栏图格可减；编号样式可换
  字数语义：标题两行内；条目名≤10 字（精确联动预算见母版 repeat 注释）

### 4.2 受控即兴（三级阶梯）与转正

- **即兴三级阶梯（绝大多数任务停在 L1/L2，L3 是罕见兜底）**：
  - **L1 直接套用**：catalog 能选到 → 用母版（默认路径）；
  - **L2 母版为底微调**：接近但不完全合脚 → 以某母版为底做局部增删（删可选槽位、条数在 repeat 区间内、槽位换图）；
  - **L3 受控即兴**：无合脚母版 → 用 style.css 既有类组合整页（layout 登记 `custom/<语义名>`）。
- **内容约束**：即兴只调整"版式对内容的呈现"，文案仍忠于素材提炼结果——**禁大幅改写内容迁就版式**；需要大改内容 = 回炉②重提炼，不是即兴能解决的事。
- 即兴边界（不变）：只用 style.css 既有类 + 遵循 design-system.md；**禁止内联样式、自造 CSS 变量、新类名**（新类=风格演进=用户过目改 style.css 并登记 design-system）。
- 即兴页校验升级：形态校验必查（根节点 / 禁区属性 / data-layer 唯一）；几何体检需显式传 `--check-geometry`，且只对 custom 页执行（§5）。
- 转正：同名 `custom/<名>` 累计 ≥2 次 → AI 提示建议入库 → 按 §3 规范重整（补标记/占位符/限制注释/入 templates.html+catalog）→ 用户目检 → 真实任务回归一次。转正不是复制粘贴当次产物。
- 即兴两次不满意同一内容 → 直接走转正管道，不无限即兴。

### 4.3 画廊（templates.html 三合一）

templates.html 既是仓库也是画廊：顶部导航（语义组锚点）+ 风格看板（色板/字体/字号/画布规格，与 style.css 同源）+ 分组区头 + 母版纵向平预览（带说明头）。浏览器打开即所见。iframe 方案弃用（它以每母版独立文件为前提，与单文件存储矛盾）。人审细节开画廊；当次出图总览看 `<交付目录>/preview.png`（§6）。

## 5. render 实例化器规格

| 项 | 内容 |
|---|---|
| 输入 | `<任务运行区>/plan.json` + 素材图片（相对运行区）；`--delivery` 或 plan.delivery 指定交付目录 |
| 步骤 | 按 layout 从 templates.html 抽 section（custom 页直用 AI markup）→ 填槽/克隆 repeat/执行 crop → **图片槽只替换 src**（`data-slot/data-layer/data-label/data-ratio` 原样保留 + 父容器补 `data-filled`）→ **含手机框槽的页才内嵌手机框**（读 `styles/assets/iphone-frame.png`，现场编码 dataURL 内嵌）→ style.css 内联（防御性剥离 `@import`）→ 图片内嵌 dataURL + 原件复制进运行区 `assets/` 作副本 → 包独立壳写 `P<nn>-<名>.html` → Chrome 逐页截图 1080×1440 → 生成 preview.png 总览 → 生成 `editor.manifest.json` + `fields.json` → **全部写入任务运行区** → 三层校验与截图全过 → 白名单拷贝交付目录（§6） |
| 输出 | 运行区：上述全部过程件与产物；交付区：默认 `P*.html` + `P*.png` + `preview.png`，`--with-editor` 追加 `fields.json` / `editor.manifest.json` / `assets/` |
| 硬校验（即停） | `{{` 残留 / 图片缺失或格式不符 / 图槽 `<img data-slot>` 缺 data-layer / 根节点与画布确认（custom 页含根类与禁区属性）/ `data-layer` 全页唯一 / 必填槽为空 / plan 字段与槽位对不上 / repeat 区间越界 / 交付目录已存在且非空（除非 `--force`）、不是目录或等于任务运行区 / `--delivery` 空值 / `--only` 空值或与交付互斥 / 手机框资产缺失（含手机框槽的页） |
| 软校验（WARN） | 字数超限（解析限制注释比对）/ 图片与槽位比例差异大（提示裁切量）·（catalog 与说明头同源同步 v1 未自动校验，靠入库纪律保证） |
| 即兴页专项 | 形态校验（根节点 `.artwork-page` + `data-artwork` + `data-size` / 无禁区属性 `position:fixed`、`@media`、`<script>`、`animation`、`transition` / `data-layer` 唯一）+ `--check-geometry`（显式开启时才做几何体检：画布溢出与元素越界，仅 custom 页） |
| 地基 | `script/render.mjs` = **生产环境固定脚本**（唯一实例化器，非临时文件）+ `script/shared/`（cdp、find-chrome）；`script/_ref/` 为上一代退役脚本，零引用、待删 |

> **受限环境适配（Chrome 沙箱）**：容器 / root / CI / macOS 沙箱下，browser 进程能起来但 renderer 一起就被杀，表现为调试管道秒关、stderr 只有 crashpad 噪声（看不到 `No usable sandbox`）。`launchBrowser` 启动后用 `data:` URL 真导航一次做冒烟，失败即自动加 `--no-sandbox` 重试**一次**（日志出现 `⚠ Chrome 首次启动失败…`）；已显式开 `noSandbox` 时不再重试，避免掩盖真实错误。

> **手机框单源（交付口径）**：`styles/assets/iphone-frame.png` 是唯一源。render 的 `getFrameDataUrl()` 读取该 PNG → 编码成 dataURL → 替换母版 `frame-img` 槽的 src，把框图直接内嵌进交付页；**PNG 本体不进交付目录**。画廊以 `../assets/iphone-frame.png` 相对路径引用同一份文件。

## 6. 交付（三级目录分离）

| 层级 | 位置 | 运行期写入 | 放什么 |
|---|---|---|---|
| ① 技能安装目录 | 本仓库（`SKILL.md` / `styles/` / `script/` / `final/`） | **只读，零写入** | 只读资产与代码；不写任务产物、不写临时脚本 |
| ② 任务运行区 | agent 临时工作区 `runs/<任务>/`（gitignore） | 读 + 写 | `plan.json`、原始素材、`shots/`、日志、`_preview.html`、`P*.html`、`P*.png`、`preview.png`、`assets/`、`fields.json`、`editor.manifest.json` |
| ③ 交付目录 | 用户选中的工作区；未指定则用 agent 默认任务文件夹 | 只写白名单 | 见下方标准包 |

- 交付目录由调用方命名 `YYYY-MM-DD-<文章小标题>/`，经 `--delivery=<路径>` 或 `plan.json` 的 `delivery` 字段给出；相对路径按当前工作目录解析。
- **顺序**：先写运行区 → 三层校验与逐页截图全部通过 → 再按白名单拷贝。任何硬错误或截图失败都不产出交付目录。
- **不覆盖**：目标目录已存在且非空即停；同一任务重跑加 `--force`（只覆盖白名单文件，不删其它内容）。目标路径若已存在但不是目录，直接报错。
- **`--only` 仅调试**：只出指定页且只写运行区，与 `--delivery` / `plan.delivery` 互斥；正式交付必须跑完整页数，否则会把单页的 preview/manifest/fields 混进交付包。
- 标准包（默认白名单）：

  ```
  YYYY-MM-DD-文章小标题/
    P01-封面.html   P01.png
    P02-清单.html   P02.png
    …
    preview.png     （当次总览拼图，人审第一眼）
  ```
- `plan.json`、素材副本、过程件一律留运行区，不进交付。交付页 HTML 自包含（CSS 内联、图片 dataURL 内嵌），故 `assets/` 只是副本，默认不进交付。
- `--with-editor` 追加：`fields.json` + `editor.manifest.json` + `assets/`（编辑器材料；T6 未做完前非必需）。
- 编辑器微调：`cd /d/AI/pageApp/demo && node pack.mjs "<含 manifest 的目录>"`（可指向任务运行区，或带 `--with-editor` 的交付目录）→ `covers-edit.html`。此命令写死本机 pageApp 绝对路径，生产安装不可用——待开发项登记于 TODO 附表（SKILL.md 对应处标【待开发】）。
