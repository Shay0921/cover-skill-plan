# 母版创建规范

> **本文是"写一张新母版 / 改一张既有母版"的唯一完整规范**。生产跑图时不需要读本文件；只有母版创建、二次开发、转正入库时必读。
> 依据：final/01 手册 §3（摘要层）+ pageApp 交接规范 v1.9（编辑器契约）。冲突时以 pageApp 契约为准。

---

## 0. 一张标准母版的解剖（七件组成部分）

一份合格母版 = 以下七件的**完整集合**，缺一即不可实例化：

| # | 组成 | 位置 | 作用 |
|---|---|---|---|
| 1 | **说明头** | section 前的 HTML 注释 | 人读 + AI 读的总说明（§4 必填字段） |
| 2 | **section 壳** | `<section data-layout="<id>">` | 风格内唯一 id，render/编辑器定位锚 |
| 3 | **画布根** | `<div class="p-page" data-artwork data-size="1080x1440">` | 一母版一页一画布根；尺寸写死在根上 |
| 4 | **槽位系统** | 元素上的 data-slot / data-layer / 占位符 | AI 填内容的唯一接口（§2） |
| 5 | **repeat 槽** | 单元旁的 repeat 注释 | 弹性条目的唯一配置点（§3） |
| 6 | **装饰层** | 手机框槽 / 底纹 / 图标位 | 不进编辑器图层的部分（data-decoration） |
| 7 | **登记三处** | catalog.md + design-system.md + 说明头 | 同源同步，缺一处即未入库 |

外加**两份样式/脚本义务**：样式进 style.css（双段制，§5）；图标等运行资源按风格约定（§7）。

## 1. HTML 规范

### 1.1 结构骨架（直接抄此骨架起步）

```html
<!-- ============ N<序号>-<语义名> · <中文标题> ============
     用途：…（一句话）
     适合：…；不适合：…；可以变：…
     限制：标题≤N字(M行)；副题≤N字；<槽位清单>；hl：…处…位置
     图槽：<比例>，竖图裁切 / 竖图禁用
-->
<section data-layout="N<序号>-<语义名>">
  <div class="p-page" data-artwork data-size="1080x1440">
    <!-- 画布内容：全部收在此根内 -->
  </div>
</section>
```

### 1.2 结构规则

- 一 section = 一页 = 一个画布根；**section 内禁止 `<style>`**（样式全进 style.css）。
- 画布固定 1080×1440；根节点带 `container-type:size`（使用 cqw 时必需）。
- 全部内容收在画布根内，不依赖外层 section / body 的 padding 定位。
- 标签白名单：常规结构标签（div/section/header/main/footer/ul/ol/li/p/h1-h6/span/img/figure/figcaption/pre/code/table 等）；**禁** form/iframe/object/embed/audio/video/canvas 动态用法；`<template>` 内不放任何正文与标记（构建期整树跳过）。
- **产物禁 `<script>`**、无动画/过渡/轮播/滚动、无外部 `<link>`、无 `<img src>` 外链（pageApp 构建期拒绝）。

### 1.3 占位符与富文本

- 文字槽内容写 `{{槽名}}`，**槽名 = data-slot 名 = data-layer id = plan.json 的 fields 键**——三处同名是硬规则。
- 富文本位允许的运行时注入标签仅：`<span class="hl">`（高亮，css 自定义颜色）、`<br>`、`<strong>`；AI 的 plan.json 字段值只能含这三类标签。
- 正文不得放 `::before/::after` 的 content（编辑器改不到）。

## 2. 槽位与 data-* 规范（编辑器契约逐字执行）

### 2.1 属性表（pageApp v1.9 §4.1）

| 属性 | 值 | 放在哪 | 忘写后果 |
|---|---|---|---|
| `data-layer` | 全页唯一 kebab-case 英文 id | 要成为图层的元素 | 图层面板无名/冲突报错 |
| `data-label` | 中文短名 | 同上 | 图层名显示为 class 字典名 |
| `data-type` | text / group / image | 同上（可省，自动推断） | 卡片被推断成 group，内部文字改不了 |
| `data-editable` | `"text"` | 包住文字的叶子元素 | 文字不可编辑 |
| `data-group` | 无值 | 组合容器 | 容器连同内部被整体拖动 |
| `data-slot` | `"image"` | **仅 `<img>`** | 换图槽位失效 |
| `data-ratio` | 如 `4:3`（本规范扩展） | 图槽容器或 img | AI 无法判断裁切方式 |

### 2.2 硬规则（违反 = 构建期报错或图层失效）

1. `data-layer` 全页唯一；只许字母数字-连字符-下划线；禁中文、空格、`#`、`.`、首尾空白。
2. **容器标 group、文字标叶子**——只标容器不标叶子 = 卡片内文字全部改不了（最常见的错）。
3. `data-slot="image"` 只能落 `<img>`；`text` 类型不能落 `<img>`；同一元素类型标记互斥。
4. 根节点不加 `data-layer`；标记不进 `<template>`。
5. 高亮 `<span class="hl">` 与 `<br>` 编辑安全，可放心用。
6. 装饰性元素（底纹/图标/页码/手机框）**不标 data-layer**（减少图层面板噪音）。

## 3. repeat 槽规范（条目弹性的唯一配置点）

### 3.1 语法（全库唯一语法定义处 = 本节；数值只写在母版注释里）

```html
<!-- repeat ×<min>-<max>: <克隆规则一句>；<条数-字数联动一句> -->
<div class="item" data-slot="items">
  <div class="num">01</div>
  <div><p class="t" data-layer="item-t" data-editable="text">{{条目标题}}</p>
       <p class="d" data-layer="item-d" data-editable="text">{{条目说明}}</p></div>
</div>
```

### 3.2 规则

1. 任何重复型组件适用（清单/待办/卡片/行/通知/图卡…）；一个母版可有多处 repeat 槽，各管各的。
2. 区间与联动字数**只配置在这一条注释里**；catalog 只写语义（"弹性条目清单"）不写数字。
3. 布局必须用 flex/grid 弹性实现（`flex:1` 均分等），保证区间两端都不溢出、不空塌。
4. plan.json 传数组 → render 克隆并**校验区间**（超出 ×min-×max 即停）；AI 不手工复制节点。
5. 克隆单元内的 data-layer id 由 render 加序号后缀（item-t-2、item-t-3…），母版只写第一份。

## 4. 说明头规范（必填字段清单）

每个 section 前的注释块必须含全部字段，缺一即未入库：

```html
<!-- ============ N10 工具清单 ============
     用途：工具/资源/方法的并列推荐页
     适合：3-8 条量级推荐，左文右图；不适合：每条长说明；可以变：右栏图格可减
     槽位：title / sub / items[]（num,t,d）/ 图×6
     限制：标题两行内；条目名≤10字；说明一句话；图槽 1:1，竖图裁切
     hl：标题内 0-1 处
     来源：AI Efficiency Lab #11
-->
```

- "限制"行是 render 字数软校验的解析对象——**写实测值**（该字号下不折行不溢出），不写感觉值。
- 说明头与 catalog.md 条目**同源同步**：改一处另一处跟改。

## 5. CSS 规范（双段制）

### 5.1 归属判定（唯一问题）

> "这个类会不会被第二个母版复用？" —— 会/可能 → **共享段**；不会 → **专属段 + 母版前缀**（如 `.n10-tool-list .item` 或 `.n10-item`）。

### 5.2 纪律

| 项 | 规则 |
|---|---|
| 文件位置 | 全部样式进 `styles/<风格>/style.css`；section 内禁止 `<style>` |
| 令牌优先 | 颜色/字号/间距一律用 `var(--token)`（tokens 在 style.css 顶部 :root 或 style-guide 定义）；新令牌 = 风格演进 = 用户过目 |
| 单位 | px 或 cqw（cqw 需根节点 container-type:size）；**禁** vh/vw |
| 选择器 | 扁平（≤2 层）；禁 CSS 嵌套语法（编辑器未验证） |
| 禁区 | `position:fixed`、窗口断点 `@media`、动画/过渡/滚动 |
| 弹性设计 | 重复区必须弹性（flex/grid 均分），条数变化自动伸缩；关键区域预留行数余量；不依赖 nowrap 保布局 |
| 命名 | 类名小写连字符；组件类用语义名（card/row/badge/tag）；专属类必须带母版前缀 |

## 6. 图片与资产规范

- 图槽必须声明 `data-ratio`（或由 css aspect-ratio 定死）；素材与槽位比例不符 → `object-fit:cover` 居中裁切；**杂乱图**由 AI 在 plan.json 写 `crop` 选区。
- 手机壳母版：截图槽 + `frame-img` 装饰槽（不标 layer）；**框图由 render 自动从 styles/assets/iphone-frame.b64 解码兜底**，母版里不内嵌框图、不引外部框图文件。
- 允许格式 PNG/JPEG/WebP；SVG/GIF/AVIF 禁（pageApp 构建期拒绝）。
- 风格 assets/ 只装母版 markup 直接引用的静态装饰资源；示例截图不进库（画廊 iframe 实时渲染）。

## 7. 字体规范

- 中文：本机字体栈（"PingFang SC","Microsoft YaHei",sans-serif）——编辑器导 PNG 唯一安全路径。
- 西文展示字体：小体积（latin 子集）由 render 出页时 base64 内嵌；**不在源模板引 CDN**（编辑器导 PNG 必然回退）。
- webfont 粗体：需对应字重的 fontsource CSS，不得浏览器合成假粗体。

## 8. 创建工作流（七步 · 新母版从 0 到入库）

1. **定位**：读 design-system.md + catalog.md，确认语义空缺（哪个组缺哪类内容）、写好四栏草案。
2. **起草**：复制同风格最相近的既有母版（或本文件 §9 骨架）到新 section，改版式结构与类名（专属类即加前缀）。
3. **上样式**：共享段优先收录（判定见 §5.1），真专属进专属段；禁局部 `<style>`。
4. **打标记 + 占位符 + 限制注释**：按 §2/§3/§4 逐项完成；槽名三处同名。
5. **假文字自检**：最长文案（取限制上限）不溢出、最短不空塌；repeat 槽取区间两端各试一次；暗色（若有）再试一遍。
6. **机器校验**：render 出单页（或 pageApp 打包器试跑）——三层校验全过、图层面板检查（每个要改的字都在）。
7. **入库四登记**：templates.html（含画廊导航锚点）+ catalog.md 条目 + design-system.md 组件语义 + style-picker.md（仅新风格时）；用户目检通过即正式。

**二次开发（改既有母版）的三层边界**：

| 动作 | 层级 | 规则 |
|---|---|---|
| 填内容 / 改条数（区间内）/ 换图 | 任务适配 | plan.json 解决，不碰母版 |
| 改某母版的结构/槽位/限制数值 | 改母版 | 同步 catalog 条目 + 说明头（同源）；用户目检 |
| 改共享类 / 新增组件类 / 改令牌 | 风格演进 | 用户过目改 style.css + design-system.md 登记（影响全风格所有母版） |

删除母版 = 用户裁决（catalog/design-system/导航锚点三处同删）。

## 9. 最小合规示例（可直接抄改）

```html
<!-- ============ N99 双栏金句 ============
     用途：单句主张 + 左右双要点
     适合：观点/转场页；不适合：多图内容
     槽位：title / left-t / left-d / right-t / right-d
     限制：title≤14字(2行)；要点 t≤10字 d≤18字；hl：title 内 1 处
-->
<section data-layout="N99-two-col-quote">
  <div class="p-page" data-artwork data-size="1080x1440">
    <h1 class="big-title" data-slot="title" data-layer="n99-title" data-label="金句标题" data-editable="text">{{金句标题}}</h1>
    <div class="col" data-layer="n99-left" data-label="左要点" data-type="group">
      <p class="t" data-slot="left-t" data-layer="n99-left-t" data-label="左标题" data-editable="text">{{左标题}}</p>
      <p class="d" data-slot="left-d" data-layer="n99-left-d" data-label="左说明" data-editable="text">{{左说明}}</p>
    </div>
    <div class="col" data-layer="n99-right" data-label="右要点" data-type="group">
      <p class="t" data-slot="right-t" data-layer="n99-right-t" data-label="右标题" data-editable="text">{{右标题}}</p>
      <p class="d" data-slot="right-d" data-layer="n99-right-d" data-label="右说明" data-editable="text">{{右说明}}</p>
    </div>
  </div>
</section>
```

（配套：`.big-title/.col/.t/.d` 上收 style.css 共享段；若仅本母版使用则 `.n99-*` 进专属段。）

## 10. 验收清单（入库/转正前逐条打勾）

- [ ] 七件组成齐备（§0）；说明头字段全（§4）
- [ ] 结构合规：一 section 一页一画布根；零局部 `<style>`；无标签禁区（§1）
- [ ] 槽位三处同名；富文本白名单内（§1.3）
- [ ] data-* 过 §2.2 六条硬规则；装饰层不标 layer
- [ ] repeat 注释含区间+联动字数；布局弹性验证两端（§3）
- [ ] CSS 双段制归属正确；令牌优先；无禁区属性；扁平选择器（§5）
- [ ] 图片槽有 data-ratio 且在图片决策表归类；手机框走兜底（§6）
- [ ] 字体策略合规（§7）
- [ ] 四登记完成且同源（templates/catalog/design-system/style-picker）
