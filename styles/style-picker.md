# style-picker.md · 风格选择器

> **用法**：AI 按"适合文案"推荐 1-2 种风格给用户拍板（或用户直接点名）。风格细节进 catalog.md 对应段落；本文件每风格只一行名片。

## tech-blue · 极简科技蓝

气质：纯白 + 极淡网格 + 深墨衬线大标题 + 唯一强调蓝 #2563EB；杂志感、克制、专业
适合文案：AI 工具实测 / 教程 / 效率方法 / 数据报告 / 产品横评——讲道理、有截图、有数据的干货
反例：情感故事、探店种草、节日热点、需要多色活泼感的轻内容
入口：`styles/tech-blue/templates.html`（画廊）· `catalog.md#tech-blue`（32 母版选型）· `styles/tech-blue/design-system.md`（即兴纪律）
