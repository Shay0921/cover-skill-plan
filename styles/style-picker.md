# style-picker.md · 风格选择器

> **职责**：只回答一件事——"这篇内容用哪个风格"。选母版进该风格目录的 catalog.md；填表规则在母版说明头；即兴/改风格的边界在该风格 design-system.md。

## 选型动线（固定三步）

1. **定风格**：按下面各风格名片推荐 1-2 个给用户拍板（或用户直接点名）；需要看版式时打开该风格 `templates.html` 画廊（带占位符，不是成品效果）；
2. **选母版**：读 `styles/<风格>/catalog.md`，按语义组 + 四栏为每页选版式；
3. **填表**：读选中母版的说明头与 repeat 注释（精确条数/字数的唯一来源）。

## 风格目录构成（全库唯一权威定义）

每风格一个目录，四个必交文件：`templates.html`（母版仓库=画廊）、`style.css`（唯一样式）、`catalog.md`（选型牌桌）、`design-system.md`（风格规范）。其余为可选或定版后产出：

- `styles/assets/` 是**跨风格共享层**（手机框等共享资源），不属于任何单个风格目录。
- `<风格>/assets/` 是可选子目录，只放本风格独有的装饰资源（tech-blue 当前没有）。
- **当前仅 `tech-blue` 激活可用**；`paper-journal/` 目录在库但**未激活**，选型动线不可选用它。
- `style-preview.png` = 风格定版后由用户按统一文案一次性生成的预览图（画廊 `templates.html` 带占位符、不适合直观预览）；非必交文件。

## 语义组名（全库统一 · 9 组）

封面 / 步骤 / 清单 / 对比 / 演示 / 数据 / 转化 / 结尾 / 内容
（组名跨风格对照用；组内多张牌 = 同类内容的不同排版变体）
（组是选型入口，不是配额：单张成组、同一母版重复使用都正常。）
（**封面是开篇首选池，不是专用组**：定第 1 页先从这个风格的封面组挑，中段同样可用；别组的牌也能当第 1 页——页码只看 `nn`，第 1 页自动隐藏。组里有几张牌以该风格 catalog 为准。）
（**内容是密集信息页组**：术语速查、人群适配、Agent 入口这类「信息块多、不能做成大标题 Hero」的页从这里挑；标题角色与字号判定见该风格 `design-system.md` §1.1，不由组名决定。）
