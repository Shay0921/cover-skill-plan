# catalog.md · 配方总目录

> **用法**：AI 依 style-picker.md 定风格后，读本文件对应风格段落选母版。四栏 = 选型判断；精确条数/字数在选中母版的 repeat 注释与说明头里（本目录只写选型语义）。
> **同源纪律**：本目录与各母版说明头同源同步，改一处另一处跟改（render 校验）。
> **图槽约定**：所有图槽为 `<img data-slot="image">`，比例见条目；杂乱图在 plan.json 写 crop 选区，裁切由 CSS 机械执行。

> 纯白底 + 40px 极淡网格 + 深墨标题 + 唯一强调色 #2563EB。衬线标题 / 无衬线正文 / 等宽标签。杂志感、克制、AI 效率类内容的首选。画廊：`styles/tech-blue/templates.html`。
