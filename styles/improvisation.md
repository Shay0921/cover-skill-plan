# 即兴补空（借壳补空）

> 母版能套、版式没问题、但某块留白或空框难看时的人工补空路径：以最贴近的母版为底抄整页骨架，在空处插现成组件、内容写死，以 custom 页出图。不改母版、不改代码。

## 触发（两型）

- **留白型**：条目少，页面下方空一片（如时间线母版三条目）。
- **空框型**：弹性条目被 `flex:1` 拉高，内容顶对齐，框内下方空（如数据卡母版小卡）。

共同点：版式没问题，内容量撑不满。**内容装不下不归这里管**——回炉按 `references/content-refinement.md` 提炼文案，或换母版。条数低于母版舒适区（如流程页只有 3-4 条）时**换母版或补空二选一**，由内容决定：没有更合适的母版、或就是想保留这条流程叙事，补空就是正路。

## 做法（5 步）

1. `plan.json` 复制目标页：`layout` 改成 `custom/<语义名>`，`name` 照填，新增 `markup` 字段放整页 HTML；不要给 custom 页写 `fields`（它不做槽位填充）。
2. `markup` = 从 `templates.html` 抄该母版 `<section>` 里的 `<div class="artwork-page …">` 整段（根保留该母版专属类，壳、品牌栏、页脚一起抄）。
3. **系统槽手填**（custom 页不做任何注入）：品牌三槽从 `plan.meta.brand` 抄值；期号按本页语义写（issue 是逐页值）；页码手写 `NN / 总页数` 格式，**封面页（nn=01）把页码节点整个删掉**；其余槽直接写真实文案。
4. **插组件补空**：留白型插在 `.content` 里空着的位置；空框型插进**被拉高的那个框内部**（框外插块不消除框内空白）。**间距与贴底的现实边界**：全库没有间距或撑开工具类、即兴禁内联样式——插入块只能就近缩短空白带，不保证贴底填满：flex 纵向容器（如 N25 小卡）内可用 `margin-top:auto` 把块推到框底，block 容器（如 N05 的 `.content`）没有这个手段。同一处留白反复出现 → 修母版自身的弹性（条目分布、容器 flex），那是母版侧的活，补空替代不了。某槽没有内容同理走这条通道：把对应元素整块删掉再出图（即选型牌桌说的「L2 删元素」）。
5. 出图：`node script/render.mjs <运行区>/ --check-geometry`（几何体检恰好只对 custom 页生效，记得带；要交付加 `--delivery`），人审 PNG。

## 常用配方：N23 对话窗整块换图

聊天窗（N23）在"对话演示"与"整图展示"之间二选一：plan 直接填对话 = 对话形态；要图形态 = 抄 N23 骨架为 custom 页，把 `.n23-chat` 整个 div 换成图槽容器（`.ph-img` + img base64 内嵌 + 手补 `data-filled`），`flex:1` 撑满原窗位置。**必须配竖屏截图**（原窗是竖向满窗，16:10 横图会左右大幅裁切）。

## 组件从哪借

- **共享段直接借**（根带不带母版类都生效）：胶囊 `.pill`（`.num` 是序号位，必须挂在 `.pill` 里面，不能单独挂）、`.callout` 说明条、`.fine-*` 弱结构、`.accent-*` 强调四式、字级类 `.title-*` / `.num-large` / `.body-text` / `.mono-text` / `.label`。完整清单见所选风格 design-system「画布骨架与共享组件」表（类名以 tech-blue 为例）。
- **借专属段组件分两种**：选择器独立、无祖先要求的纯前缀类可跨母版借；带祖先前缀的（如 `.n25 .content`）必须根带对应母版类，且**一个根只挂一个**母版类，否则两套规则打架。
- 借来的块若带 `data-layer`，改成新 id——与页面现有层撞名会被 custom 检查拦下。
- **图槽**：唯一可靠写法 = 图片转 base64 内嵌进 `<img src>`（不要写 `assets/` 路径——custom 页不做素材收集，交付目录也没有 `assets/`）；内嵌后在 `.ph-img` 容器上手动加 `data-filled`，或直接删掉 `.ph-img__label` 占位标签节点，否则占位文字浮在图上。

## 三条硬约束

1. **`{{…}}` 一个不留**：custom 页不做槽位填充，render 对 `{{` 残留即停（硬校验），留一个就是一页坏图出不来。
2. **根类三件套**：`artwork-page` + `data-artwork` + `data-size="1080x1440"`；`data-layer` 页内唯一。这是 custom 分支机器硬检的其中两项（另有 `{{` 残留、禁区属性，见 CONTRACT「custom 页」一节），过不了直接停。
3. **只用本风格已有的类**：`position:fixed` / `@media` / `<script>` / `<animate>`（及 SVG 同类 `<animateMotion>`/`<animateTransform>`/`<set>`）/ `animation:` / `transition:` 会被硬停（大小写不敏感，完整清单见 CONTRACT「custom 页」）；内联样式、自造 CSS 变量、新类名机器不拦但属违规，靠人审把关。

## 出图后自查

- **字数没有告警**：custom 页不走说明头限值——超字靠目检，重点看标题折行与溢出。
- **封面页码已删**；全文搜一遍 `{{`（render 会拦，自查是提前发现）。
- **编辑器不受影响**：文字可编辑性来自 markup 里的 `data-layer` 标记，抄来的壳上都还在；期号/页码不会自动生成，进编辑器手动改。

## 边界与转正

- 同一类缺空在 ≥2 页出现 → 是母版本身该修，提请用户改母版，不逐页补。
- **转正（本文件是唯一细则点，SKILL 只留指针）**：AI 是这件事的责任方——**主动识别、主动向用户提出**，不等用户开口。
  - **触发判据**：同一 `custom/<名>` 在多次任务中反复出现，或同一处补空改了两版仍不满意。跨任务复用**无自动计数**（plan 每任务重建、运行区随用随清），靠 AI 凭跨任务记忆主动判断；判断成立即提出，不要求用户先发现。
  - **转正四步**：① 向用户提出入库建议 → ② 按 `final/03-母版创建规范.md` 重整为正式母版（说明头七字段 + section + 专属 CSS + catalog 条目）→ ③ 目检 + 一次真实任务回归 → ④ 入库。转正是纯人工流程（无计数脚本、无 auto-promote）。
- **不在即兴页里手绘 SVG**：即兴纪律禁内联样式、禁新类名，手绘 SVG 没有合法的样式通道（机器不拦）；要图走 `references/FIGURE-GUIDE.md` 出 PNG 填图槽。
