# tech-blue · design-system.md

> tech-blue 风格规范：气质 / 设计令牌 / 组件语义表 / 自绘图形 / 即兴纪律 / 反例。

## 0. 一句话气质

安静的杂志感科技蓝：纯白底铺 40px 极淡网格，深墨衬线大标题，全库只有一个强调色 #2563EB，等宽小字做标签与页码。

## 4. 即兴补空纪律

**本节只管即兴补空页**（`custom/<名>`，无 `layoutBase`）：它没有任何样式通道，只能借母版骨架、用既有类。自由组合页不受本节约束——那一类放行页内 `<style>` 与自造类，视觉值走令牌校验，见 `references/COMPOSED-MODE.md` §5。

- 母版能套但留白/空框难看时，借母版骨架补空：触发、做法与硬约束见 `references/IMPROVISATION.md`；本节只立风格纪律。
- 只用 style.css 既有类；根结构照抄母版：`.artwork-page.n<nn>` + `.paper-noise` + `.brand-top` + 内容 + `.pg-footer`。
- 禁：内联样式、自造 CSS 变量、新类名、`<style>`、vh/vw、position:fixed、@media、动画/过渡。
- cqw 优先于 px（画布内自适应）；间距只用 `--space-*` 令牌（14 档，0.2–6.6cqw 值即名；`--space-page` 专做画布边距），行高 / 字距 / 圆角同样只走 `--lh-*` / `--ls-*` / `--radius-*`，不写裸值。
- 版式自适应用 flex/grid 弹性（`flex:1` 均分），不做固定高度堆叠。
- 即兴页 layout 登记 `custom/<语义名>`；几何体检需显式 `--check-geometry`（仅 custom 页）；同名 custom 累计 ≥2 次走转正管道（`SKILL.md`「手写页与转正」）。

### 4.1 整块换图的配方（N23 对话窗）

聊天窗（N23）在「对话演示」与「整图展示」之间二选一：plan 直接填对话 = 对话形态；要图形态 = 抄 N23 骨架为 custom 页，把 `.n23-chat` 整个 div 换成图槽容器（`.ph-img` + img 写相对路径、出图自动内嵌 + 手补 `data-filled`），`flex:1` 撑满原窗位置。**必须配竖屏截图**（原窗是竖向满窗，16:10 横图会左右大幅裁切）。

## 5. 大数字的去留（big-num / step-num）

带大数字的母版默认显示大数字，但**大数字不是必填宿命**——它只在「数量本身是这页主角」时才留。

- **判据**：能否用一句话把数量说成卖点——「6 条速览」「7 倍增长」「3 步搞定」？能 → 留大数字；不能（这一页讲的是一个主张、一张图、一组对比，数字只是条数的机械统计）→ 走轻量标题，去掉大数字。
- **决策权**：由 AI 在选母版/写 plan 时按判据判断，**人审可否决**（人审说去掉就去掉，不辩论）。不逐页问用户——这属于内容判断，不是需要用户拍板的风格选择。
- **实现**：big-num / step-num 槽已标 `data-optional`，plan 填 `""` 即隐藏（契约见 `references/CONTRACT.md`「键名与系统槽」）；标题侧 `flex:1` 占满整行、按实际宽度断行（字数校验只卡总量，与数字无关）。**例外**：N26 的 `n26-center-price` / N27 的 `n27-center-no-num` 是写死的居中特例——不可填，只可借其写法、不可照抄成可填槽。
- **判据自检**：去掉大数字后标题若显得空、撑不起整行 → 说明这一页本就该有数量主角，改回留数字，或换一个本就无数字的母版（封面 N01–N03、结尾 N28–N31）。

## 6. 反例

- 引入第二个强调色（红/绿/紫）；强调色只用 `--accent`（blue-600），深版 `--accent-deep`。
- 卡片一律大圆角；卡片/面板/窗口圆角只按三级令牌（.4 / .8 / 1.4cqw），胶囊、圆形等特殊形态沿用既有实现值，不自造新档。
- 用无衬线粗体当大标题；大标题必须用衬线（`--serif`）。
- 给数据页的涨跌写死方向色（涨蓝/跌橙）。plan 只能改文字、切不了类，方向色会把「耗时下降」染成涨色，等于让版式篡改内容；方向交给 +/− 号，颜色只做标注底。
- 为了「像图表」手动接柱状图。柱高是母版里的固定百分比，plan 改不了，数据和柱形对不上就是假图表；要真实比例请自绘图形出 PNG，或改用文字条带/表格。
- 用 per-page `fields` 逐页填品牌名/logo/页脚署名；品牌三值走顶层 `plan.meta.brand.*`，期号 `issue` 逐页填，页码禁止手填。
- 图槽塞 `<div style="background:url()">`；图槽必须走 `<img data-slot="image">`。
- 把 `repeat ×min-max`、每槽 `≤N字` 精确限值写进 catalog；精确限值只在母版注释与说明头，catalog 只写选型量级语义。
