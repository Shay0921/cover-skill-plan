# tech-blue · catalog.md（选型牌桌）

> **用法**：各栏只写**选型语义**——条数区间、行数、形态（「短标」「一小段」）、能否留空，用于判断内容装不装得下。精确限值（`≤N字` / `≤N字符` / `repeat ×min-max`）只在母版说明头「限制」行与 repeat 注释，不进本表；图槽比例例外，见下条。
> **图槽约定**：图槽 = `<img data-slot="image">`，图片按 `data-fit` **裁切填满、不拉伸**；槽位比例统一用固定常用比声明——16:9 / 16:10 / 4:3 / 3:2 / 1:1 / 4:5 / 3:4 / 2:3 / 9:16，盒形零头偏差由裁切吸收；异形槽（手机屏、横长条、Bento 格）保留实测比，条目只标方向与张数。「图槽」行比例与母版 `data-ratio` 同源同步，改一处另一处跟改。杂乱图在 plan.json 写 `crop` 选区，裁切由 CSS 执行。**无图槽的页**（母版内自带图形的 N33）条目写「图形：……」，不接受图片。用户截图与自绘图形（按 design-system §3 现画、`figure.mjs` 出的 PNG）同权。
> 组名沿用全库统一语义分类学（10 组），见 style-picker.md「语义组名」。

## 封面

#### N01 金句震撼封面
适合：单句主张 + 数据点撑场的开篇；观点/实测类
不适合：多图内容；长标题
可以变：数据 1-4 项；标签 0-4 个；高亮词可移位
字数语义：标题两行内；副题一行；按语一行（精确预算见母版说明头）

#### N02 对话框封面
适合：教程/Prompt 类开篇，有横版截图
不适合：无图可用；竖图（裁切严重）
可以变：按钮文案可变（btn-1/btn-2）；小注可省
字数语义：标题两行内；副题一行
图槽：窗口横图 16:9 ×1

#### N03 通知堆叠封面
适合：自动化/Agent/日报类主题，通知卡片堆叠
不适合：需要大图时
可以变：通知 2-4 条；首条默认蓝色高亮（CSS 自动，无需手工）
字数语义：标题三行内（每行短）；通知标题/正文各一行内；标签与图标字极短

#### N04 手机叠放封面
适合：手机 App 类，双手机叠放展示竖屏截图
不适合：横图
可以变：可减为一台手机（L2）；框图由 render 自动内嵌
字数语义：标题两行内；看板标题/说明各一行
图槽：手机屏竖图 ×2（cover）

## 概览

#### N05 时间线概览
适合：Day N 叙事、阶段复盘的时间线
不适合：无时间含义的并列内容
可以变：条目 3-5 条；末条强调款需 L2；提速标注可留空
字数语义：条目标题/说明各一行；时间为短标（如「Day 3」）

## 步骤

#### N06 单步骤深度详情
适合：有 2-3 张过程截图的单步教学，图文混排
不适合：无截图纯文字
可以变：三段各带 strong 强调；图注可留空
字数语义：段落两行内；图注一行；代码两行内
图槽：横长条 ×3（cover）

#### N07 单步骤概览
适合：一张主截图讲一个动作 + 三要点
不适合：多步骤并列
可以变：要点 2-4 条；强调款需 L2
字数语义：要点两行内；Tip 两段
图槽：横版 16:9 ×1

#### N08 双步骤同页
适合：教程前两步打包讲（第 1 组带截图）
不适合：超过 2 步（拆 N06/N07）
可以变：每组要点 2-3 条
字数语义：步骤标题一行；要点一行
图槽：横版 16:9 ×1

#### N09 步骤前后对比
适合：旧方法 vs 新方法对照 + 底部收获条
不适合：三项以上对比
可以变：收获条可省（L2）
字数语义：栏标题/描述/代价各一两行；收获数字短
图槽：横版 16:10 ×2

#### N33 流程链路图（内置 SVG）
适合：4 步方法论 / 内容链路 / 处理流水线的全局一览——一页把整条链路说完
不适合：步数≠4（3 步或 5 步另开档，或走 L3）；这一页需要展示真实界面
可以变：节点标题、节点说明、收尾一句话全部可改；节点数固定 4
字数语义：大数字=步数；节点标题短词；节点说明一行；收尾一句话一行
图形：2×2 节点 + 走向箭头，由母版内 SVG 绘制（**无图槽，不支持换图**）

## 清单

#### N10 工具清单
适合：3-8 条工具/资源推荐 + 右栏图格，左文右图
不适合：每条需要长说明（d 只有一行）；纯图片展示
可以变：条目 3-8 条（行距自适应）；图格固定 6 格可 L2 减
字数语义：大数字=条数；条目名一行；条目说明一行（精确联动见母版 repeat 注释）
图槽：竖版 3:4 ×6

#### N11 工具清单基础
适合：3-7 条推荐，纯文字（编号+名称+描述+分类标签）

可以变：条目 3-7 条行高自适应；标签可留空
字数语义：大数字=条数；名称/描述各一行

#### N12 待办清单
适合：5-8 条行动清单（勾选框 + 进度头）
不适合：无勾选语义的纯列表（用 N11）

字数语义：大数字=条数；条目/条目注各一行

#### N13 Prompt 教程
适合：4-6 步 Prompt 公式教学（编号 + 示例等宽块）
不适合：无示例内容
可以变：步骤 4-6 条均可；满配 6 条时标题须 2 行内（细则只在母版说明头，此处不复制）
字数语义：步骤名/示例各一行；页脚公式一行

#### N14 误区避雷
适合：4-6 条认知纠偏（✗误区 → 正解）
不适合：正面教程

## 对比

#### N20 Before/After 大对比
适合：两种路径/工具对照（双栏任务清单 + 数据格）

适合：一张界面图的分步导览（编号钉 + 对应说明）
