# tech-blue · catalog.md（选型牌桌）

> **用法**：各栏只写**选型语义**——条数区间、行数、形态（「短标」「一小段」）、可省项，用于判断内容装不装得下。可省项直接写结果：能留空的写「可为 0」或「没有就删掉该行」，需要手删节点 / 手加类 / 改 markup 的写清动作。精确限值（`≤N字` / `≤N字符` / `repeat ×min-max`）只在母版说明头「限制」行与 repeat 注释，不进本表；图槽比例例外，见下条。
> **条目 slug**：标题后反引号内为该母版的 layout slug，与 `templates.html` 的 `data-layout` 一一对应——plan.json 的 `layout` 抄它；两侧改名必须同步，发现不一致以 templates 为准（真源）。
>
> **大数字可去**：下表各条目若写「大数字=条数/图数/…」，表示默认显示；但大数字不是必填——数量不是这页主角时 plan 填 `""` 即自动隐藏（可选槽机器语义见 `references/CONTRACT.md`「键名与系统槽」；去/留判据见 `styles/tech-blue/design-system.md`「大数字的去留」）。
> **图槽约定**：
> - 图槽 = `<img data-slot="image">`，图片按 `data-fit` **裁切填满、不拉伸**；贴边内容会被切。
> - 比例统一用固定常用比声明——16:9 / 16:10 / 4:3 / 3:2 / 1:1 / 4:5 / 3:4 / 2:3 / 9:16，盒形零头偏差由裁切吸收；异形槽（手机屏、横长条、Bento 格）保留实测比，条目只标方向与张数。图槽行比例与母版 `data-ratio` 同源。
> - 乱图在 `plan.json` 写 `crop` 选区；不写则整图按 `data-fit` 裁切填满。写法见 `references/CONTRACT.md`「图槽」。
> - **无图槽的页**分两类：纯文字母版（多数档，如 N01/N12/N25/N30，条目照常写文字槽语义）与图形母版（母版内自带 SVG 的 N33/N35，条目写「图形：……」，不接受图片）。
> - 用户截图与自绘图形（按 design-system「自绘图形」节现画、`figure.mjs` 出的 PNG）同权。
>
> 组名沿用全库统一语义分类学（10 组），见 style-picker.md「语义组名」。

#### N04 手机叠放封面 `N04-phone-stack-cover`

#### N33 流程链路图（内置 SVG · 固定四步） `N33-flow-4`
适合：4 步方法论 / 内容链路 / 处理流水线的全局一览——一页把整条链路说完

#### N35 流程时间轴（内置 SVG · 固定四段） `N35-flow-timeline`
适合：按时间推进的四段流程总览（冲煮分段、操作时序）——一条主线讲完节奏
不适合：段数≠4；分支/汇合流程；这一页需要展示真实界面
可以变：节点名/参数/时间、底部三项汇总全部可改；**段数固定 4**
字数语义：大数字=段数；节点名短词；参数/时间一行；汇总项短
图形：横向时间轴 + 4 节点 + 走向箭头 + 底部 3 项汇总，母版内 SVG **写死的四段示意**（**无图槽，不支持换图**）；分支/汇合/自由布局走 FIGURE-GUIDE 自绘 PNG
