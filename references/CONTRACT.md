# 机器契约（CONTRACT）

> 写 `plan.json` 的 AI 与机器的约定。**只登记机器报不出错的语义**——静默行为、裁切判断、坐标参照系；能被 `script/render.mjs` 报错拦住的写法不在此文，照报错改即可（报错指着出错那一行说话，不会过期）。与代码冲突时以代码为准。

## 1. 键名与系统槽

- 文字槽 = 母版里的 `{{占位符}}`；图槽 = `<img>` 的 `data-layer`；坐标槽 = `data-pin`。
- `data-layer` 是编辑器图层 id，**可能与占位符不同名**（`{{t}}` ↔ `tool-t`、`{{btn-1}}` ↔ `n02-btn-1`）。**别按 `data-layer` 猜文字槽键名**，以说明头「槽位」行为准。
- 系统槽 6 个：`brand-logo` / `brand-name` / `footer-id` 取 `meta.brand`（整组统一，不写逐页 fields）；`issue` 逐页填；`page-no` / `progress` 机械生成，填了会报错。
- 字数超限只 WARN 不停（20% 容差内不报）；品牌三值不在 `fields`、不进字数校验，超限靠人审。富文本只认 `span.hl` / `span.hl-line` / `br` / `strong`。
- 母版标了 `data-optional` 的槽允许留空：填 `""` 即占位符清空、节点隐藏（大数字轻量标题页用）；其余槽空值报错。

## 2. 图槽 crop（唯一会静默毁图的一节）

机器只验「语法能不能解析」，验不了「裁得对不对」——裁错不报错，只出一张错图。以下每条都查不出来：

- `上/下/中 N%` 裁**高度**方向（保留横条带）；`左/右 N%` 裁**宽度**方向；裸 `N%` = `下 N%`。
- **`中` ≠ `center`**：`中 55%` = 垂直居中的横条带；`center 55%` = 水平居中的竖条带。
- **叠加模型**：crop 先把图片盒子放大成条带（高或宽 = 100 ÷ 比例），再由 `object-fit:cover` 二次适配。所以方位要针对**裁后净可见区**判断，不是按原图整体估。
- 百分比越界（<5 或 >99）只 WARN，并按边界值处理——写 100% 和写 99% 效果不同。
- 图与槽比例差很多时，先在运行区按槽比例**预裁**成新文件再引用：文件级比例校验只读原图尺寸，plan 里的 `crop` 不参与比对，所以靠 crop 消不掉比例 WARN。
- 图路径必须是运行区内相对路径（`shots/a.png`）；格式 PNG / JPEG / WebP（GIF 会被自动转成 PNG 再入图）。

## 3. 坐标槽 data-pin（机器只验格式，验不出钉错地方）

- 值是**要标注的目标点**在截图里的百分比坐标（0–100），看图直接给，不手算。
- 参照系由母版 `data-pin-frame` 声明：`stage` = 手机内屏截图内的位置；`percent` = 截图框内的位置。AI 不改该属性，照母版说明写。
- 不传坐标 = 保留母版默认钉位，不算缺槽；同一 repeat 单元的多个坐标按克隆后缀传（`note-pos`、`note-pos-2`）。

## 4. custom 页：机器不做的三件事

- 图：转 base64 内嵌进 `<img src>`，容器补 `data-filled` 或删占位标签。custom 页不收集素材，也不查这个。
- 页码与品牌三槽要**手写**（custom 页不注入）；封面页把页码节点整个删掉。
- 内联样式、新类名、自造变量机器不拦，但属违规，人审把关。

## 5. 其余全部交给报错

字段名对不上（会附最近匹配建议）、必填槽为空、repeat 条数越界、图不存在或格式不符、`contain` 槽写 `crop`、根类三件套、`{{` 残留、`data-layer` 重复、禁区属性、手填 `page-no` / `progress`——`render.mjs` 都会指出页号与位置，照报错改，不必提前背。
