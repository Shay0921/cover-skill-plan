# 机器契约（CONTRACT）

> 写 `plan.json` 的 AI 与机器的约定。**只登记机器报不出错的语义**——静默行为、裁切判断、坐标参照系；能被 `script/render.mjs` 报错拦住的写法不在此文，照报错改即可（报错指着出错那一行说话，不会过期）。与代码冲突时以代码为准。

## 1. 键名与系统槽

- 文字槽 = 母版里的 `{{占位符}}`；图槽 = `<img>` 的 `data-layer`；坐标槽 = `data-pin`。
- `data-layer` 是编辑器图层 id，**可能与占位符不同名**（`{{t}}` ↔ `tool-t`）。**别按 `data-layer` 猜文字槽键名**，以说明头「槽位」行为准。
- 系统槽 6 个：`brand-logo` / `brand-name` / `footer-id` 取 `meta.brand`（整组统一，不写逐页 fields）；`issue` 逐页填（母版页走 fields；**组合页没有 issue 注入通道**，写死在 markup）；`page-no` / `progress` 机械生成，填了会报错。
- 字数超限只 WARN 不停（20% 容差内不报）；品牌三值不在 `fields`、不进字数校验，超限靠人审。富文本只认 `span.hl` / `span.hl-line` / `br` / `strong`。
- 可选槽 = **文字槽** + 母版上标了 `data-optional`。填 `""` 即占位符清空、由 CSS `:empty` 隐藏节点——节点不删、版面不塌（大数字、角标签、小注这类「数量不定」的槽）。repeat 单元内的可选槽同样适用。
- 没标 `data-optional` 的文字槽空值报错；图槽缺失一律报错。机器不支持空数组，repeat 区间见说明头 `repeat ×min-max`。

## 2. 图槽 crop（唯一会静默毁图的一节）

机器只验「语法能不能解析」，验不了「裁得对不对」——裁错不报错，只出一张错图。以下每条都查不出来：

- `上/下/中 N%` 裁**高度**方向（保留横条带）；`左/右 N%` 裁**宽度**方向；裸 `N%` = `下 N%`。
- **`中` ≠ `center`**：`中 55%` = 垂直居中的横条带；`center 55%` = 水平居中的竖条带。
- **叠加模型**：crop 先把图片盒子放大成条带（高或宽 = 100 ÷ 比例），再由 `object-fit:cover` 二次适配。所以方位要针对**裁后净可见区**判断，不是按原图整体估。
- 百分比越界（<5 或 >99）只 WARN，并按边界值处理（`Math.min(99, Math.max(5, n))`）。因此**写 `100%` 与写 `99%` 渲染结果完全相同**——都按 99% 处理；唯一区别是 `100%` 会多一条 WARN。想让告警消失就写 99%，别以为两者裁切量不同。
- 图与槽比例差很多时，先在任务工作区按槽比例**预裁**成新文件再引用：文件级比例校验只读原图尺寸，plan 里的 `crop` 不参与比对，所以靠 crop 消不掉比例 WARN。
- 图路径必须是任务工作区内相对路径（`shots/a.png`）；格式 PNG / JPEG / WebP（母版图槽的 `fields` 引用 GIF 会自动取首帧转 PNG；**custom 页内联 `<img>` 不支持 GIF**，静态单跑与出图都会要求先转码）。
- **`data-ratio` 常用比**（图槽与 catalog 条目的默认写法）：16:9 / 16:10 / 4:3 / 3:2 / 1:1 / 4:5 / 3:4 / 2:3 / 9:16 / 2:1。实测异形保留原比、不归并进这组——效果图槽 8:3，手机屏族 46:99，横长条与 Bento 格同理。合法值只要求「数字:数字」，机器不校验是否在此集合内；写集合外的比时，盒形体检会拿它跟实测盒比对，偏差 ≥15% 报 WARN。填充型槽（盒高由 flex 决定）不写 `data-ratio`。

## 3. 坐标槽 data-pin（机器验格式 + 三条粗检，钉错地方仍验不出）

- 值是**要标注的目标点**在截图里的百分比坐标（0–100），看图直接给，不手算。
- 参照系由母版 `data-pin-frame` 声明：`stage` = 手机内屏截图内的位置；`percent` = 截图框内的位置。AI 不改该属性，照母版说明写。
- 不传坐标 = 保留母版默认钉位，不算缺槽；同一 repeat 单元的多个坐标按克隆后缀传（`note-pos`、`note-pos-2`）。
- **默认常开的三条软告警**（`stage` 型钉位，不需要 `--check-geometry`）：`y` 贴上下边（<10 或 >90，卡片可能溢出舞台）；部分传入（钉位形态不一致）；同侧两卡 `y` 间距 <18%（卡片可能重叠）。三条都只 WARN、不改版面。
- **仍然验不出**：钉错了目标对象、卡片遮住关键内容、左右侧选反、`percent` 型钉位的任何位置问题。

## 4. custom 页：分两类，别混着记

`custom/` 下有两条路，机器待遇不同。**有 `layoutBase` = 组合页，无 = 即兴补空页**（规则详见 `COMPOSED-MODE.md`）。判档 fail-closed：`layout` 以 `custom/composed-` 开头也按组合页处理，此时漏写 `layoutBase` 直接硬停，**不会退回即兴补空**。

| 项 | 即兴补空页（无 `layoutBase`） | 组合页（有 `layoutBase`） |
|---|---|---|
| 图 | 写 `<img src="相对任务工作区路径">`，出图时自动转 base64；容器补 `data-filled` 或删占位标签（否则占位文字浮在图上）。**静态单跑也查 src**：缺 src / 空 src / 路径越界 / 文件不存在 / 扩展名与内容不符 / 外链 / `srcset` 均硬拦（`shared/image.mjs`，与 render 同一份） | 同左 |
| 品牌三槽 / 页码 | **手写**（不注入）；封面把页码节点删掉 | **惰性注入**：写了 `data-sys` 就由 render 填（值取 `plan.meta.brand` 与页序），没写保留手写值；页码节点内须有 `{{page-no}}`，`nn=01` 自动隐藏，不必删节点 |
| 内联样式 / 页内 `<style>` 块 | **硬拦**（`checkCustomBasics`：补空页没有样式通道） | 内联 `style=` 硬拦；页内 `<style>` **放行**，但视觉值须过 `page-css.mjs` 令牌关闭集 |
| 无定义类名 / 自造 CSS 变量 | 机器不拦，人审把关（仍是违规） | 硬拦：`composed.mjs` 禁无定义类名与母版专属类 |
| 页内 `<style>` 自造组件 | **机器不拦，人审把关** | 放行：类须在页内有定义，视觉值（字号/行高/字距/圆角/间距/色值）须走令牌，布局属性自由；主标题错档由 CDP 对位拦 |
| 根三件套 / 禁区 / `data-layer` 唯一 | 硬拦（`checkCustomBasics`；render 与 `composed.mjs` 单跑同一份实现） | 同左 |
| `{{}}` 占位符 | 硬拦：注入跑完后残留即停（`render.mjs` 内联，文案按通道分两句，此页一条都不填） | **两道**：`checkComposed` 先按名字拦非注入占位符（`{{issue}}` 这类在静态阶段就能点名），注入后再由 render 查残留。单跑 CLI 只有第一道 |

## 5. 两层体检：默认软告警 vs 显式开关

出图日志分两层，**别把「没传开关」当成「没检测」**：

- **默认常开（软告警，只 WARN、不改版面）**：图槽盒形比例偏差 ≥15%（§2，阈值与应对见 `IMAGE-WORKFLOW.md`）；坐标槽三条钉位粗检（§3）；文字槽字数超限 20% 容差（§1）。`custom/` 页另加类名与填充类的组合提示（`COMPOSED-MODE.md` §7）。
- **需显式 `--check-geometry`**（**只对 `custom/` 页生效**，母版页不查）：元素溢出画布扫描（逐个列出越界元素，命中即停）+ **custom 页硬检**（补空页与组合页都查）——叶子文本块互相压盖 ≥25%、标题末行孤字与 `.fine-line` 塌陷、密度欠填（**实际覆盖率 <40% 或 跨高 <70% 或 尾白 >18%，任一命中**），**组合页另加全量字号 ∉ 18 档**，任一命中即停；最大字间空隙 >20% 与正文末行孤字只 WARN（人审）。**交付硬门槛**：plan 里只要有一页 `custom/*`，交付必须带 `--check-geometry`，没带直接拒绝交付（防止手写页绕过体检进成品）。密度把 `.content` 内文本与 img/svg 的矩形一起计入覆盖区间（图主导页不会被判欠填；绝对定位的图照样算），只排除画面上没有图形的空 `<svg>` 与面积不足 `.content` 6% 的装饰性小图标（否则一枚页底小图标就能把尾白压成 0）。覆盖率是主判据：只看跨高会被「首尾各一个元素、中间全空」骗过。根节点 `data-density="airy"` 的页密度只报数值不拦。判据详见 `COMPOSED-MODE.md` §4.2/§7。它们不重复上面那些默认软告警，也不替代人审 PNG。

## 6. 其余全部交给报错

字段名对不上（会附最近匹配建议）、文字槽为空（可选槽除外）、repeat 条数越界、图不存在或格式不符、`contain` 槽写 `crop`、根类三件套、`{{` 残留、`data-layer` 重复、禁区属性、手填 `page-no` / `progress`——`render.mjs` 都会指出页号与位置，照报错改，不必提前背。
