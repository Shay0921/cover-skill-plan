# 图片与图形来源决策链（Image Workflow）

`SKILL.md`「工作流程」第 4 步（识图盘点）、第 5 步（逐页定版式）、第 6 步（定裁切）的展开：每页的图从哪来、怎么放、要不要裁。这是 AI 行为决策；`crop` 选区的写法见 `CONTRACT.md`「图槽」，与代码冲突时以 `script/render.mjs` 为准。

一页的图有三条来路，**按页分别判断，不是整篇只走一条**：

| 路径 | 什么时候走 | 怎么产出 | 落点 |
|---|---|---|---|
| ① 用户素材 | 用户给了截图/照片 | 直接用 / 手机壳联合 / 按四列表选槽裁剪 | 图槽 |
| ② 自绘图形 | 文案要讲流程/概览/大纲/关系，没有现成图 | 固定结构用母版 SVG；复杂结构 `figure.mjs` 写 HTML 出 PNG | 母版 SVG 或图槽 |
| ③ AI 生图 | ①②都不合适，且用户允许 | 调当前 agent 的生图模型生成位图 | 图槽 |

判断顺序：有现成图先走①；没有、但该页讲结构走②；既无图、又不是讲结构、只是要氛围/概念画面，才考虑③——且必须先问用户。

## 路径① 用户素材

一条链走完：**看图 → 归类 → 选槽 → 需要才裁**。裁切优先在 plan 写 `crop` 选区（方向 + 百分比）；图与槽比例差很多时先预裁素材（见「看图与裁图纪律」），不做修图级像素加工。

选槽的落点是 catalog：每张母版说明头有「图槽」行写该母版收什么图（如「手机屏竖图 ×2」「窗口横图 16:9」「竖版 3:4 ×6」），按画面形态与张数找匹配的那行；找不到就换母版。

**图数与槽数不匹配**：多图按文案语义排优先级取满槽数，弃图在素材清单注明原因并向用户说明；图不够时先换图槽更少的母版，仍不够则保留占位标签并在交付说明里列出缺素材，不默认补 AI 生图。

| ① 看图：这是什么 | ② 归类 | ③ 选槽（在 catalog 找「图槽」行） | ④ 要不要裁 |
|---|---|---|---|
| 手机 UI 截图（状态栏/底栏在） | 手机模型图 | 找标「手机屏竖图」语义组的母版（单机到三机都有）；截图自带外框时改用不限定形态的图槽，避免双框 | 不裁，整图进壳 |
| 窗口/网页/代码截图，或画面完整的照片 | 图片或截图 | 按形态找「窗口横图 / 横版 / 竖版 / 方图 / Bento」等图槽；不能裁的方形图（二维码等）用 `contain` | 不裁；比例差异大先核对 `data-ratio` 声明 |
| 主体偏一角、边框杂乱、有无关 UI | 需裁剪图 | 按主体朝向找图槽母版 | **读图定位主体 → 写 `crop` 取包含主体的一段**（如「下 55%」「left 30%」） |
| 主体在角落/需居中局部（二维取区） | 需裁剪图 | 同上 | **禁 `crop` 硬写——直接预裁**（crop 只支持单轴条带，做不出二维取区） |
| 无现成图，但页要讲清关系/结构 | 需自画图 | **→ 转路径②** | — |

### 素材清单（第①步的落盘）

看图不能只在脑子里过：第 4 步把结果写进任务工作区的 `素材清单.md`，每张图一行——

| 文件 | 尺寸/比例 | 主体位置 | 留白/可裁区 | 判定类型 | 语义与候选去向（这图讲什么 → 第 5 步定的槽，此时只写候选） |
|---|---|---|---|---|---|
| shots/a.png | 1170×2532 ≈ 0.46 | logo 在右下 | 左侧大片留白可弃 | 需裁剪图 | 讲支付流程 → 候选：左文右图类母版图槽 |
| shots/b.png | 1179×2556 ≈ 0.46 | 整屏设置页（状态栏/底栏在） | 无 | 手机模型图 | 讲设置项 → 候选：手机屏竖图槽，不裁 |

清单是写 plan 的依据，也是人审的核对物：写的主体位置跟原图对不上，说明图没看；尺寸/比例列把「比例差很多」的判断前置到选槽。**「去向」这一列第 4 步只写候选**——具体落哪个槽、要不要 `crop`，等第 5 步定了母版（第 6 步定裁切）回填，否则等于在不知道槽形态的情况下先选槽。图多时弃选图的语义可只写关键词，不必长篇。清单只落任务工作区，不进交付。

### 看图与裁图纪律

选图和裁图都从「看图」开始，看图要回答两件事：**图里讲的是什么事**（语义）、**重点在哪个方位**（主体位置）。后者直接决定 `crop` 的方位词，前者决定这张图该不该进这个槽——两者不能只答一半。

- **语义对齐（先读文案再选图）**：读该图槽的 `data-label` 与紧邻的图注/段落文案，图里讲的事必须和文案是同一件。「认出了正确的图却填进错误的槽」比裁切比例不准更致命——先核对语义，再谈比例。图与文案对不上就换图或重选区域，不硬裁一张语义不符的图。
- **截图/完整图默认不裁**——裁掉的是证据，先用换槽和核对比例解决，裁是最后手段。
- **看图定位主体再写值**：主体在上半写 `上`、贴右写 `right`、居中写 `中`；别凭文件名猜，看不清主体唯一方位就不写 `crop`、标注需人审，禁止猜方位。方位词写错，裁得再准也会切掉重点。
- **选区宁大勿小**（裁图主策略）：估主体边界宁多留不多切——多留的部分由 cover 收尾裁掉，切掉的就找不回来了。方位针对**裁后净可见区**判断（`crop` 先放大成条带、cover 再二次适配，见 `CONTRACT.md`「图槽」叠加模型），不是原图整体；写完过一遍「裁后主体还在不在」。
- **图与盒形对不上就重备素材**：填图时若图的比例与图槽 `data-ratio` 差很多（量化锚点：偏差 ≥15%，即机器盒形体检的 WARN 阈值），cover 会二次裁切吃掉内容——在任务工作区按声明比例**预裁出新素材文件**再引用（原图保留、预裁件只落任务工作区），或换一张比例贴合的图；别把不贴合的图硬塞进槽，也不靠拉伸。
- **预裁的方法（零依赖）**：写一次性脚本放任务工作区，用 CDP 打开页面把原图读进 `<img>`，`canvas.drawImage(img, sx, sy, sw, sh, 0, 0, tw, th)` 按槽的 `data-ratio` 重绘取窗（窗口取包含主体的区段），`toDataURL('image/png')` 存为新文件。四条要点：只做等比重绘、不拉伸；产物与原图文件名区分（如 `<名>-<比例>-<方位或序号>.png`——同图裁多段必须带后缀，防同名互覆与 `--only` 静默用错图）落任务工作区、不进交付；预裁件生成后**回看一眼**确认主体在窗内再入 plan；取哪段由看图决定——canvas 是精确重裁，不受 `crop` 单轴条带限制。相机照片混入时先处理 EXIF orientation（浏览器按其转正显示而像素头宽高不变，比例判断与取窗会错位）。
- **预裁与 `crop` 是串行不是二选一**：比例差很多先预裁归一比例，主体仍偏角时**在预裁件上补 `crop` 微调**——此时 plan 图槽的 `src` 必须指向预裁产物，禁止仍指原图却期待 crop 作用于预裁结果。
- **裁完仍不理想或含隐私/分辨率低** → 换图或换母版，**不靠加 `crop` 硬救**；确实与语义无关就挪到展示类页面。

### 一图多用

同一张图允许在不同页复用，按内容判，不按文件判：

- **原样重复**（同一区域出现在多页）→ 不建议，读者会觉得凑数；封底回顾等刻意呼应除外。
- **裁不同区域讲不同事** → 允许。一张长截图上半是设置项、下半是数据面板，分两页各裁一段，读者看到的是两条信息，本质是两张图。
- 判据一句话：**裁出来的内容是不是在讲两件事**。是 → 允许；不是 → 换图。
- 别指望靠 `crop` 从一张图里挖出多块：它只支持单轴条带（上/下/左/右 + 百分比），做不出「保留右上角」这种二维取区。

## 路径② 自绘图形

同一语义组里「图槽母版」和「图形母版」一个是证据、一个是结构，不能互相顶替：要证明「真东西长这样」用截图（路径①），要解释「它们之间什么关系」才自绘。

- **反向判据**：把这张图换成纯文字表格，信息会不会丢？会丢 → 画图；不会丢 → 别画。
- **红线**：图形不得伪造界面——禁止用 SVG/CSS 画假窗口、假对话框、假数据面板冒充截图。
- **两种画法**：固定 3/4/5 步的整齐结构 → 图形母版（SVG 在母版里、节点字是文字槽，可改）；形状写不死（多轨/分支汇合/矩阵）→ 图槽母版 + `figure.mjs` 写 HTML 出 PNG 当图片填槽（文字变像素、交付后不能改字）。
- **图形必须先于 plan 出发**，且先定风格。通用机制见 `FIGURE-GUIDE.md`，风格专属标定见该风格 `design-system.md`「自绘图形」节。
- **即兴页（custom）不手绘 SVG**：机器不拦，但即兴纪律「禁内联样式、禁新类名」让手绘 SVG 没有合法的样式通道——即兴页要图就走 `figure.mjs` 出 PNG 填图槽；母版内嵌 SVG 仅属于图形母版（catalog 里标「图形：」的条目）。

## 路径③ AI 生图

只在①②都不合适、且用户允许时走。生图能力由当前 agent 平台提供，skill 自身不内置模型；生成结果当普通图片填槽，走与路径①相同的槽位与裁剪规则。

- **先问、一次问完**：用户没给素材又确实需要画面时，一次性说明三种走法（用户自己提供 / 自绘图形 / AI 生成），推荐用户自己的素材但不强推；用户选了就照办，不反复劝导、不中途二次追问。
- **不默认生成**：没问过用户不能自己生图。
- **图只管画面**：生成的位图只匹配本页视觉角色、不做通用装饰；图上不要嵌标题、页码、logo 或假 UI，文字一律交给母版文字槽——AI 出图里的文字最容易露馅。
- **比例直接对槽**：生成时按目标图槽的 `data-ratio` 指定出图比例（生图模型支持设比例，但档位离散——取最接近的一档，差值仍大时靠预裁或 cover 收尾），省一次预裁。
- **限量**：通常只用在真能增值的 1-2 页，不要整篇铺满生成图。
- **生图先自审再填 plan**：AI 能看自己生成的图——明显失败品（畸形、错字、构图崩）直接重生成或弃用，不进 plan。
- **人审留意**：交付前看 PNG 时顺带检查 AI 印记（多手指、变形字、光照断裂），有问题就重生成或换图。
