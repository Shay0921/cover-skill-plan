# 即兴补空

> 母版能套、版式没问题、但某块留白或空框难看时的人工补空路径：以最贴近的母版为底抄整页骨架，在空处插现成组件、内容写死，以 custom 页出图。不改母版、不改代码。

## 触发（两型）

- **留白型**：条目少，页面下方空一片（如时间线母版三条目）。
- **空框型**：弹性条目被 `flex:1` 拉高，内容顶对齐，框内下方空（如数据卡母版小卡）。

共同点：版式没问题，内容量撑不满。**内容装不下不归这里管**——回炉按 `CONTENT-REFINEMENT.md` 提炼文案，或换母版。条数低于母版舒适区（如流程页只有 3-4 条）时**换母版或补空二选一**，由内容决定：没有更合适的母版、或就是想保留这条流程叙事，补空就是正路。

## 做法（5 步）

1. `plan.json` 复制目标页：`layout` 改成 `custom/<语义名>`，`name` 照填，新增 `markup` 字段放整页 HTML；不要给 custom 页写 `fields`（它不做槽位填充）。
2. `markup` = 从 `templates.html` 抄该母版 `<section>` 里的 `<div class="artwork-page …">` 整段（根保留该母版专属类，壳、品牌栏、页脚一起抄）。
3. **系统槽手填**（本条只适用即兴补空页——它不做任何注入；组合页走了惰性注入，见 `COMPOSED-MODE.md` §3）：品牌三槽从 `plan.meta.brand` 抄值；期号按本页语义写（issue 是逐页值）；页码手写 `NN / 总页数` 格式，**封面页（nn=01）把页码节点整个删掉**；其余槽直接写真实文案。
4. **插组件补空**：留白型插在 `.content` 里空着的位置；空框型插进**被拉高的那个框内部**（框外插块不消除框内空白）。**间距与贴底的现实边界**：共享段只有两枚填充类可用——`.fill-grow{flex:1;min-height:0}`（均分拉伸，给要吃掉剩余高度的块）、`.fill-sink{margin-top:auto}`（把末块推到底）；给目标块挂上即可，**别再手写内联 `margin-top:auto`**。它们要求父容器是 flex 纵列，block 容器上无效；居中骨架挂 `.fill-sink` 反而会把内容顶到底、空出一大片。其余情况下插入块只能就近缩短空白带，不保证贴底填满（哪些容器属哪类，查所选风格 `design-system.md` 的组件表）。同一处留白反复出现 → 修母版自身的弹性（条目分布、容器 flex），那是母版侧的活，补空替代不了。某槽没有内容同理走这条通道：把对应元素整块删掉再出图。
5. 出图：`node script/render.mjs <任务工作区>/ --check-geometry`（补空页要查：越界扫描 + 密度 / 压盖 / 标题孤字塌陷；组合页**另加**全量字号扫描——补空页没有样式通道、字号必然来自 `style.css`，故不扫；刻意留白（封面金句、收尾大字）在根节点写 `data-density="airy"` 申报，没申报的欠填会硬停；软告警默认常开，见 `CONTRACT.md`「两层体检」；要交付加 `--delivery`），人审 PNG。

## 组件从哪借

- **共享段直接借**（根带不带母版类都生效）：胶囊（序号位必须挂在胶囊内层、不能单独挂）、说明条、弱结构类、强调四式、字级类——**具体类名查所选风格 `design-system.md` 的组件表**（tech-blue 示例：`.pill` / `.callout` / `.fine-*` / `.accent-*` / `.title-*`）。
- **借专属段组件分两种**：选择器独立、无祖先要求的纯前缀类可跨母版借；带祖先前缀的选择器（如某母版专属容器类）必须根带对应母版类，且**一个根只挂一个**母版类，否则两套规则打架。
- 借来的块若带 `data-layer`，改成新 id——与页面现有层撞名会被 custom 检查拦下。
- **图槽**：写 `<img src="shots/a.png">`（相对任务工作区路径），出图时自动复制进交付 `assets/` 并把 src 改写为相对路径；markup 里仍写任务工作区路径，不要手写 `assets/`（那是脚本生成的交付路径）。容器加 `data-filled` 或删掉 `.ph-img__label` 占位标签，否则占位文字浮在图上。写了 `<img>` 就必须给图，无 src 会硬停。

## 四条硬约束

1. **`{{…}}` 一个不留**：补空页不做槽位填充（只有组合页有惰性注入），render 对 `{{` 残留即停（硬校验），留一个就是一页坏图出不来。
2. **根类三件套 + 层名唯一**：`artwork-page` + `data-artwork` + `data-size="1080x1440"`；`data-layer` 页内唯一。这两项机器硬检，过不了直接停。
3. **不进禁区**（两条手写通道通用，组合页同样适用）：`position:fixed` / `@media` / `@import` / `@font-face` / `url(` / `<script>` / `<animate>`（及 SVG 同类 `<animateMotion>` / `<animateTransform>` / `<set>`）/ `animation:` / `transition:` 会被硬停，大小写不敏感，机器报出具体命中项。图只能走 `<img src>`，不能用 CSS `url()` 引外链或本地资源。
4. **只用本风格已有的类**（补空页专属）：补空页没有样式通道——**内联 `style=` 和页内 `<style>` 块都是硬拦**，要自己写样式就走 `COMPOSED-MODE.md`。自造 CSS 变量、新类名机器不拦，但属违规，靠人审把关。

## 出图后自查

- **字数没有告警**：custom 页不走说明头限值——超字靠目检，重点看标题折行与溢出。
- **封面页码已删**；全文搜一遍 `{{`（render 会拦，自查是提前发现）。
- **编辑器不受影响**：文字可编辑性来自 markup 里的 `data-layer` 标记，抄来的壳上都还在；期号/页码不会自动生成，进编辑器手动改。

## 边界与转正

- 同一类缺空在 ≥2 页出现 → 是母版本身该修，提请用户改母版，不逐页补。
- **转正（本文件是唯一细则点，SKILL 只留指针）**：AI 是这件事的责任方——**主动识别、主动向用户提出**，不等用户开口。
  - **触发判据**：同一 `custom/<名>` 在多次任务中反复出现，或同一处补空改了两版仍不满意。跨任务复用**无自动计数**（plan 每任务重建、任务工作区随任务结束清理，技能不落 `runs/` 日志），靠 AI 凭跨任务记忆主动判断；判断成立即提出，不要求用户先发现。
  - **转正四步**：① 向用户提出入库建议 → ② 重整为正式母版（说明头七字段 + section + 专属 CSS + catalog 条目，二进制细节以正式母版文件为准）→ ③ 目检 + 一次真实任务回归 → ④ 入库。转正是纯人工流程（无计数脚本、无 auto-promote）。
- **不在即兴页里手绘 SVG**：即兴纪律禁内联样式、禁新类名，手绘 SVG 没有合法的样式通道（机器不拦）；要图走 `FIGURE-GUIDE.md` 出 PNG 填图槽。
